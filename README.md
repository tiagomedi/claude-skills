# remote-skills

Marketplace de Claude Code con skills sin plugin publicado. Cada plugin apunta a la carpeta de la skill en su repo original de GitHub, así que no hay copias aquí.

```bash
claude plugin marketplace add tiagomedi/claude-skills
claude plugin install security-audit@remote-skills
```

Para instalar todas las skills (los plugins oficiales y los de este marketplace):

```bash
bash install.sh
```
